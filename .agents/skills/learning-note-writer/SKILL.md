# Learning Note Writer

IRON LAW: 只回写稳定结论；临时想法、一次性 workaround、未验证判断不进长期文档。

## 职责

把教学过程中反复出现、已经教懂或仍需复习的知识点、场景、误区、检验结果和对应外部参考链接写成分层文档草稿。

## 工作流

- [ ] Step 1: 读取 `.agents/skills/references/documentation-layering.md`
- [ ] Step 2: 判断回写层级：design、learning、decision、stage summary 或不回写
- [ ] Step 3: 提炼知识点、触发场景、用户卡点、纠偏过程、掌握状态、验证结果和参考资料链接
- [ ] Step 4: 输出文档草稿或执行明确的文档更新
- [ ] Step 5: 标出后续需要复查的未决点

## 输出格式

- 回写位置：
- 为什么值得回写：
- 知识点：
- 触发场景：
- 用户卡点：
- 纠偏要点：
- 掌握状态：
- 适用范围：
- 非目标：
- 参考资料：
- 验证结果：
- 未决点：

## 反模式

- 不要把聊天全过程整理成流水账。
- 不要把学习笔记和架构决策混写。
- 不要为了“有产出”强行写文档。
- 不要把没教过、没检验过的知识写成用户已掌握。
- 不要把外部资料只留在对话里；用过就写入对应知识点的参考资料。
