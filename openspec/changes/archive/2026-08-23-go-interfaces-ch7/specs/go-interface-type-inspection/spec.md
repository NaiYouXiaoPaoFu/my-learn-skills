## ADDED Requirements

### Requirement: 类型断言与类型开关

教学方案 MUST 让学习者能安全地从接口值检查具体类型或附加接口能力，并区分断言失败的单返回形式、双返回形式和类型开关的适用场景。

#### Scenario: 安全类型断言
- **WHEN** 学习者不确定接口值是否包含 `fmt.Stringer`
- **THEN** 学习者能使用 `v, ok := x.(fmt.Stringer)` 判断成功与否，而不是让失败断言直接触发 panic

#### Scenario: 类型开关
- **WHEN** 一个函数需要针对少量已知具体类型选择不同处理逻辑
- **THEN** 学习者能使用类型开关覆盖具体类型、接口类型或默认分支，并说明这会引入对类型集合的显式依赖

#### Scenario: any 与泛型约束边界
- **WHEN** 需要在运行时接收未知类型，或需要在编译期复用同一算法并保留类型信息
- **THEN** 学习者能分别判断普通接口/`any` 与泛型约束的适用场景，而不把接口变量当作泛型类型集
