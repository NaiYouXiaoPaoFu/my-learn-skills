## ADDED Requirements

### Requirement: 接口值与 nil 边界

教学方案 MUST 让学习者能区分接口变量的静态类型、动态类型、动态值，并判断 nil 接口与携带 nil 指针的接口在比较和调用时的差异。

#### Scenario: nil 接口判断
- **WHEN** 一个接口变量没有被赋予任何具体值
- **THEN** 学习者能说明其动态类型和动态值均为空，接口与 `nil` 比较为真

#### Scenario: 携带 nil 指针
- **WHEN** 一个接口变量被赋予类型为 `*T` 的 nil 指针
- **THEN** 学习者能说明接口本身不等于 `nil`，并能识别后续调用是否安全取决于 `T` 的方法实现

#### Scenario: 方法集导致的赋值边界
- **WHEN** `T` 只有值接收器方法而 `*T` 同时拥有值接收器和指针接收器方法
- **THEN** 学习者能判断 `T` 与 `*T` 分别能赋值给哪些接口，并指出接口传参不会替调用方自动取地址
