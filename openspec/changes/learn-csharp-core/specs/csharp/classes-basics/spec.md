## Purpose

让零基础学习者掌握类与对象的基础：用 class 封装数据与行为，通过 new 创建对象，理解字段、属性、构造器与静态成员的职责分工。

## ADDED Requirements

### Requirement: 类与对象创建

学习者能定义类、用 new 创建实例，并理解"类是模板、对象是实例"。

#### Scenario: 定义并实例化

- **WHEN** 需要表示一个现实事物（如学生：姓名、分数）
- **THEN** 学习者定义 class Student（含数据与行为），用 new 创建多个实例并各自持有独立数据

### Requirement: 字段、属性与构造器

学习者能区分字段与属性，理解构造器在 new 时初始化对象的时机。

#### Scenario: 构造器初始化

- **WHEN** 创建对象时需要同时传入初始数据（如 new Student("张三", 85)）
- **THEN** 学习者定义带参数的构造器并在其中赋值，能说出字段（存储）与属性（对外访问+校验）的分工

### Requirement: 静态成员

学习者理解 static 成员属于类本身而非实例，能区分何时用实例访问、何时用类名访问。

#### Scenario: 类名访问

- **WHEN** 调用不依赖具体对象数据的方法（如换算工具）
- **THEN** 学习者用 static 方法并通过类名调用，能解释与实例方法的调用差异
