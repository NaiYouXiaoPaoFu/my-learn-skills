## Purpose

让零基础学习者掌握方法（函数）的定义、调用、参数与返回值，理解方法作为代码复用单元与作用域边界的作用。

## ADDED Requirements

### Requirement: 方法定义与调用

学习者能定义带参数和返回值的方法并调用，理解 main 之外的代码通过方法组织。

#### Scenario: 计算并返回

- **WHEN** 需要重复计算两个数的和/差
- **THEN** 学习者定义带两个参数、返回 int 的方法并多次调用，能说出实参与形参的对应关系

### Requirement: 参数传递与默认值

学习者理解按值传递、可选参数与命名参数。

#### Scenario: 可选参数

- **WHEN** 方法某个参数多数时候取默认值
- **THEN** 学习者用可选参数（默认值）定义并允许省略该实参调用

### Requirement: 作用域

学习者理解局部变量作用域与变量遮蔽，能解释"在哪个花括号块内可见"。

#### Scenario: 块内变量

- **WHEN** 在 if 块内声明的变量在块外被引用
- **THEN** 学习者能预判编译错误，并解释作用域规则
