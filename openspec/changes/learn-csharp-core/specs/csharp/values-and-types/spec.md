## Purpose

让零基础学习者掌握 C# 的变量声明、内置类型、类型推断与转换，能正确选择类型表达数据并解释常见类型错误。

## ADDED Requirements

### Requirement: 变量与常量声明

学习者能声明并初始化变量与常量，理解"先声明后使用"与类型固定的含义。

#### Scenario: 声明变量

- **WHEN** 学习者需要保存一个整数、一个小数、一个布尔值与一段文本
- **THEN** 分别使用 `int`、`double`、`bool`、`string` 声明并赋值，能说出各类型可存的数据种类

#### Scenario: 常量

- **WHEN** 学习者用 `const` 声明常量后尝试重新赋值
- **THEN** 编译器报错，学习者能解释常量不可变的原因

### Requirement: 类型推断与转换

学习者理解 `var` 由初始化表达式推断类型，区分隐式转换与显式转换（cast），并能解释精度丢失风险。

#### Scenario: var 推断

- **WHEN** 学习者用 `var` 声明变量
- **THEN** 能说出编译器据初始值推断出的实际类型，并能解释"var 不是无类型"

#### Scenario: 显式转换精度丢失

- **WHEN** 将 `double` 显式转换为 `int`（如 `(int)3.9`）
- **THEN** 结果为 3（截断），学习者能解释小数部分被丢弃、可能丢失精度

### Requirement: 常见类型错误识别

学习者能读懂编译器关于类型不匹配的错误信息并修复。

#### Scenario: 类型不匹配赋值

- **WHEN** 将 `string` 赋值给 `int` 变量
- **THEN** 编译器报错，学习者能根据错误信息指出问题并用转换或换类型修复
