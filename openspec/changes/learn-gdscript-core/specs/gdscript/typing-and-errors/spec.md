## Purpose

建立渐进式类型、警告和错误定位能力，使学习者能在 GDScript 的灵活性与可维护性之间做出有依据的选择。

## ADDED Requirements

### Requirement: 学习者能使用渐进式类型

学习者 MUST 能使用显式类型、`:=` 类型推断、返回类型、`Variant`、`is`、`as` 和转换，并能说明静态检查与运行时检查的边界。

#### Scenario: 为高风险接口加约束
- **WHEN** 计分函数被多个脚本调用且参数类型混乱
- **THEN** 学习者能为参数和返回值添加合适类型，并解释收益与限制

### Requirement: 学习者能定位常见错误

学习者 MUST 能区分解析错误、类型错误、运行时错误和生命周期相关错误，并使用警告、assert、日志和断点形成最小复现。

#### Scenario: 修复预置缺陷
- **WHEN** 游戏启动或运行中出现错误
- **THEN** 学习者能从首个有意义的报错定位到代码路径，修复后再次验证行为
