## Purpose

建立 GDScript 与 Godot 脚本文件的基础心智模型，使学习者能创建、运行并解释最小脚本，而不是把它误认为 Python 方言。

## ADDED Requirements

### Requirement: 学习者能解释脚本结构

学习者 MUST 能识别注释、缩进代码块、`extends`、变量、常量、函数和脚本实例之间的关系，并能创建可运行的最小 Godot 项目。

#### Scenario: 创建并运行最小脚本
- **WHEN** 学习者在 Godot 4.x 项目中创建脚本并运行场景
- **THEN** 脚本能被解析，入口行为可观察，学习者能指出脚本附着的节点

### Requirement: 学习者能使用基础值与表达式

学习者 MUST 能使用布尔、整数、浮点、字符串、空值、向量、运算符、变量、常量和枚举，并预测基本表达式结果。

#### Scenario: 修改值而不破坏表达式
- **WHEN** 需求从固定分数改为可更新分数
- **THEN** 学习者能选择变量而非常量，修改赋值并解释结果
