## Purpose

验证学习者能把 GDScript 语言、Godot 运行模型和质量设计连接起来，独立完成需求变化与缺陷修复。

## ADDED Requirements

### Requirement: 学习者能独立完成小型2D脚本闭环

学习者 MUST 能从需求拆出场景树、脚本职责、数据资源和通信关系，并实现输入、状态、帧更新、UI、信号、异步或计时、配置和错误处理。

#### Scenario: 实现并解释可运行功能
- **WHEN** 给出角色、收集物、计分、UI和一次需求变更
- **THEN** 学习者能完成可运行实现，解释数据流和生命周期，并在变更后保持原功能

### Requirement: 学习者能调试和迁移

学习者 MUST 能修复一个预置解析/类型/运行时或生命周期缺陷，说明定位证据，并把同一设计迁移到新的小需求。

#### Scenario: 综合checkpoint
- **WHEN** 随机抽取一个需求变更和一个隐藏缺陷
- **THEN** 学习者能先预测、再运行验证、定位修复、解释取舍，未验证内容明确标记为未掌握
