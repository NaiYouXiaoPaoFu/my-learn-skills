## Purpose

掌握资源化数据和编辑器集成，使学习者能把配置与运行逻辑分离，并理解导出属性和工具脚本的边界。

## ADDED Requirements

### Requirement: 学习者能加载和使用资源

学习者 MUST 能区分场景资源、Resource 数据资源、`preload` 与 `load`，并能为可配置游戏数据选择合适的存储方式。

#### Scenario: 配置多个物品
- **WHEN** 物品数值需要在编辑器中调整且被多个场景复用
- **THEN** 学习者能创建资源化配置并让运行逻辑读取它，而不是复制常量

### Requirement: 学习者能使用编辑器可见属性

学习者 MUST 能合理使用 `@export` 等属性暴露配置，并能说明 `@tool` 脚本的执行环境、风险与适用边界。

#### Scenario: 调整角色参数
- **WHEN** 设计者需要在 Inspector 调整速度
- **THEN** 学习者能暴露有类型和边界的属性，并验证编辑器修改影响运行行为
