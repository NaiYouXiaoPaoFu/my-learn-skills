## Purpose

掌握信号和 await 的事件协作模型，使多个节点能低耦合通信，并能识别异步暂停与生命周期风险。

## ADDED Requirements

### Requirement: 学习者能设计信号通信

学习者 MUST 能声明、发射、连接和断开信号，使用 Callable 与连接选项，并能解释信号如何降低节点间直接依赖。

#### Scenario: 更新UI而不直接耦合玩家
- **WHEN** 玩家生命值变化且多个界面需要响应
- **THEN** 学习者能让状态发布信号、界面订阅信号，并说明连接建立和清理位置

### Requirement: 学习者能使用await

学习者 MUST 能使用 `await` 等待信号或协程，说明函数暂停/恢复、错误路径和对象退出后的风险。

#### Scenario: 实现可取消的冷却
- **WHEN** 技能进入冷却后节点被删除或场景切换
- **THEN** 学习者能避免悬空引用或错误更新，并验证正常完成与中途退出两条路径
