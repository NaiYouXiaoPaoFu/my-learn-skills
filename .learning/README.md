# 学习系统状态

## 设计决策

- 学习方向不预设，由用户提供的资料、项目或问题驱动。
- 不把未教学、未检验的前置知识标记为已掌握。
- 每个主题先建立单一可验证目标，再允许有限横向拓展。
- 先查官方资料，再参考高质量文档或博客，并保留来源链接。
- 使用 SQLite 保存主题、计划、检验、误区、面试复盘、来源和稳定偏好。

## 当前状态

首次使用时先创建 `learning_topics` 和 `learning_sessions`，不要预填不存在的知识掌握结论。

## 目标等级

- 0：未接触
- 1：听过但不能稳定复述
- 2：能解释基础概念
- 3：能回答常见场景
- 4：能解释取舍和边界
- 5：能独立排错
- 6：能迁移到新场景

## 回写门槛

只有用户通过检验、明确确认或同一结论在多次学习中稳定出现，才更新长期状态；每次更新写入 evidence、来源和 next_action。
